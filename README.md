# Jardins tournants

Site du groupe Jardins tournants, destiné à être publié sur jardinstournants.ecolibre.org

Page statique : HTML et CSS écrits à la main, polices auto-hébergées, aucun script tiers,
aucun traceur, aucun cookie. L'agenda des sorties est lu depuis le flux public du groupe
sur mobilizon.fr.

Tant que le contenu n'est pas validé, le site reste non référencé : voir la balise
`robots` dans les deux pages HTML et le fichier `robots.txt`.
