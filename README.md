# Jardins tournants

Site du groupe Jardins tournants, en ligne sur https://jardinstournants.ecolibre.org

Page statique : HTML et CSS écrits à la main, polices auto-hébergées, aucun script
tiers, aucun traceur, aucun cookie. L'agenda des sorties est lu depuis le flux public
du groupe sur mobilizon.fr.

## Cadre et contenu

Fichiers de cadre, propres à ce dépôt, à ne jamais écraser depuis la prévisualisation :
CNAME, robots.txt, README.md

Fichiers de contenu, identiques à ceux du dépôt jardins-tournants-preview :
index.html, mentions-legales.html, style.css, photos/, polices/

Les modifications se préparent et se relisent dans le dépôt jardins-tournants-preview,
puis les fichiers de contenu, et eux seuls, sont copiés ici.
